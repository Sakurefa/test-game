目标
----
在不添加具体游戏人口内容的前提下，为 Engine 建立可持久化的聚合人口群体表示，保留现有 scalar population 与 Mod API 的人口增减兼容，并为旧存档提供 schema 迁移。

实现
----
- 新增 `engine/population.cjs`：
  - `createPopulationGroups` 为未指定人口构成的殖民地创建一个 `unclassified` 群体。
  - `validatePopulationGroups` 校验稳定 ID、群体人口、独立维度分布、维度比例总和与总人口一致性。
  - `applyPopulationDelta` 实现人口增减：正增量进入 `unclassified`；负增量按群体人口比例扣减；拒绝总人口变为负数；候选群体验证成功后才写回。
- `engine/simulation.cjs`：世界 schema 升至 8；新殖民地建立 `populationGroups`；世界存档验证检查群体；schema 1–7 迁移时为缺少群体字段的殖民地从旧 scalar population 创建中性群体。
- `engine/mod-runtime.cjs`：将现有 `colony.population.delta` 效果接入通用群体算术，不改变 Mod effect ID 与 payload。
- `engine/index.cjs`：导出人口群体基础服务。
- `electron/storage.cjs`：schema 8 写入和 schema 1–8 读取支持。
- `package.json`：语法检查包含新 Engine 模块。
- 测试：新增 `tests/population.test.cjs`，并更新 Engine、Mod runtime、storage 与 autosave 相关测试。

数据契约
--------
殖民地保留 scalar `population` 兼容字段，并持久化 `populationGroups`。每个群体包含稳定 ID、人口数和 `dimensions`。每个维度是 category ID → proportion 映射，比例合计为 1。不同维度是独立边际统计，不推导联合比例、不自动生成笛卡尔积。群体人口总和必须等于殖民地 scalar population。

当前没有写入任何具体职业、阶级、物种、财富比例、需求篮子、工资或其他人口玩法值。新世界人口暂时全部是 `unclassified`；每日需求系统仍按 scalar colony population 聚合结算，不宣称已经实现群体级需求。
