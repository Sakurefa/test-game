二、端到端测试 Mod 夹具
----------------------
仅在 tests/mod-runtime.test.cjs 新增测试夹具，不创建实际 Mod 包或 Core 内容。

测试夹具明确选择以下示例行为：
1. 对群体 ID 与 Need Rule ID 按稳定 ID 排序，逐个评估 Rule × Group。
2. 每条需求行生成独立库存请求；requesterId = groupId，sourceId = ruleId，request ID 由 Mod 生成。
3. 若 requested 为 null，则该测试 Mod 选择抛错/中止 Hook（unknown = fail）。
4. 测试库存足够，因此将每条请求全额分配。此测试不表达或测试短缺情况下的配给政策。

此策略仅是验证 Mod 可自己组织行为的测试样例，不是正式项目规则、Engine 默认或 Core 默认。
