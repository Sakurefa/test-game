Astra Reference Library
=======================

This directory contains external research used to inform project design.
It is reference material, not an approved implementation specification.

Rules:
- Keep official explanations, community research and project recommendations distinct.
- Link sources and record game version/date when values are version-sensitive.
- Do not treat community wiki/parser output as Paradox source code.
- Summarize concepts; do not copy proprietary game data tables wholesale.
- A reference or recommendation does not authorize Engine/Mod changes.

Directories:
- VICTORIA_3/ — population, needs, economy, markets, buildings and production.
